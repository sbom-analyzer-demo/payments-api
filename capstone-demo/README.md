# payments-api

Card payment authorisation and settlement service

## Purpose

This repository is part of a controlled demonstration organisation for an MSc Cybersecurity capstone project on business-context-aware vulnerability prioritisation. Its dependency manifest is **deliberately pinned to known-vulnerable versions** so that detection and remediation can be demonstrated against a known ground truth.

**Do not use this code for anything.** It exists to be scanned.

## Expected findings

CVE-2021-23337, CVE-2021-44906, CVE-2021-3749
